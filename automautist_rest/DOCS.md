# Home Assistant Add-on: AutMAutist REST server

## Installation

Follow these steps to get the add-on installed on your system:

1. Navigate in your Home Assistant frontend to **Supervisor** -> **Add-on Store**.
2. Find the "AutoMAutist REST Server" add-on and click it.
3. Click on the "INSTALL" button.

## WARNING

This add-on will only work with AutoMAutist by Gunther Voet.
